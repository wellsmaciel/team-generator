## Como interpretar

**Confirmado** significa aceito pelo usuário na entrevista. **Proposta** significa recomendação ainda sujeita a confirmação. **Estado atual** descreve o código, e não o produto desejado. As dúvidas estão centralizadas em `pendencias.md`.

O usuário confirmou as decisões principais e a divisão das cinco tarefas restantes. Cada novo chat recebe uma tarefa específica e confirma a primeira ação antes de programar; isso não autoriza implementar todas de uma vez. Sugestões antigas de arquitetura e funcionalidades adiadas não viram requisitos por aparecerem nos documentos.
